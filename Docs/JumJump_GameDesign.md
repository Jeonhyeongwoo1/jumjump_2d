# JumJump 게임 기획서

## 0. 문서 목적

이 문서는 모바일 캐주얼 게임 `JumJump`의 초기 기획 방향을 정리하기 위한 문서다.  
레퍼런스 게임 `Hamster Jump: Cake Tower!`의 핵심 플레이 구조를 참고하되, 캐릭터와 세계관은 병아리 중심의 독자적인 콘셉트로 재구성한다.

## 1. 게임 개요

| 항목 | 내용 |
| --- | --- |
| 게임명 | JumJump |
| 장르 | 탭 타이밍 기반 수직 점프 캐주얼 게임 |

| 핵심 목표 | 장애물을 피하며 최대한 높이 올라가 최고 점수를 갱신한다 |
| 주요 감성 | 귀여움, 가벼움, 반복 도전, 수집 |

## 3. 게임 콘셉트

`JumJump`는 작은 병아리가 더 높은 곳의 둥지를 향해 계속 점프하는 캐주얼 게임이다.  
플레이어는 화면을 탭해 병아리를 점프시키고, 움직이는 발판 위에 정확히 착지해야 한다. 점수가 높아질수록 발판의 움직임과 장애물 패턴이 빨라져 긴장감이 커진다.

게임의 핵심 재미는 다음 세 가지다.

- 간단한 조작으로 누구나 바로 이해할 수 있는 접근성
- 착지 타이밍을 맞추는 짧고 반복적인 손맛

## 4. 핵심 플레이 루프

```text
게임 시작
→ 병아리가 현재 발판 위에서 대기
→ 플레이어가 화면을 탭
→ 병아리가 다음 발판으로 점프
→ 착지 성공 시 점수 증가
→ 코인/아이템 획득 가능
→ 장애물과 난이도 증가
→ 실패 시 게임오버
→ 점수와 코인 정산
```

## 5. 코어 게임플레이

### 5.1 조작

- 입력 방식은 단일 탭이다.
- 플레이어가 화면을 탭하면 병아리가 점프한다.
- 점프 방향은 현재 발판 위치와 다음 발판 위치를 기준으로 결정된다.
- 별도의 방향키나 드래그 조작은 사용하지 않는다.

### 5.2 점프

- 병아리는 포물선 형태로 다음 발판을 향해 점프한다.
- 점프 중에는 추가 입력을 받지 않는다.
- 착지 가능한 영역에 도달하면 성공 처리한다.
- 착지 영역을 벗어나거나 장애물에 닿으면 실패 처리한다.

### 5.3 발판

- 발판은 화면 위쪽에 계속 생성된다.
- 발판은 좌우로 움직일 수 있다.
- 점수가 높아질수록 발판 이동 속도, 간격, 크기가 변한다.


### 5.4 장애물

장애물은 플레이어가 타이밍을 놓치게 만드는 요소다.

예시 장애물:

- 좌우로 지나가는 벌
- 위아래로 움직이는 가시 나뭇가지
- 일정 시간 후 사라지는 발판
- 회전하는 바람개비
- 낙하하는 밤송이

초기 MVP에서는 장애물 1종만 구현한다.

### 5.5 실패 조건

- 병아리가 발판에 착지하지 못한 경우
- 병아리가 장애물에 충돌한 경우
- 화면 아래로 떨어진 경우

## 6. 점수와 난이도

### 6.1 점수

- 발판 하나에 성공적으로 착지할 때마다 점수 +1
- 연속 정확 착지 보너스는 추후 기능으로 고려한다.
- 최고 점수는 로컬 저장한다.

### 6.2 난이도 증가

| 점수 구간 | 변화 |
| --- | --- |
| 0-20 | 기본 속도, 장애물 없음 또는 낮은 빈도 |
| 21-50 | 발판 이동 속도 증가 |
| 51-100 | 장애물 등장 빈도 증가 |
| 101-150 | 발판 크기 감소, 이동 패턴 다양화 |
| 151+ | 고속 패턴, 복합 장애물 등장 |

초기 구현에서는 점수 구간에 따라 발판 이동 속도와 장애물 등장 빈도만 조정한다.

## 7. 보상과 재화

### 7.1 기본 재화

| 재화 | 용도 |
| --- | --- |
| 씨앗 | 기본 게임 재화, 스킨 구매 |
| 별 | 희귀 보상, 특수 스킨 또는 꾸미기 구매 |

MVP에서는 `씨앗` 1종만 사용한다.

### 7.2 획득 방식

- 게임 중 씨앗 아이템 획득
- 게임 종료 후 점수에 비례해 씨앗 지급
- 광고 시청 보상으로 씨앗 추가 획득
- 일일 보상은 추후 기능으로 분리

### 7.3 보상 공식 초안

```text
기본 보상 = 점수 / 5
게임 중 획득 씨앗 = 직접 획득한 개수
광고 보상 = 최종 씨앗 보상 x 2
```

## 9. 파워업

파워업은 게임 중 획득하거나 광고 보상으로 제공할 수 있다.

| 파워업 | 효과 |
| --- | --- |
| 보호막 | 장애물 1회 충돌 방어 |
| 느림 효과 | 일정 시간 장애물과 발판 속도 감소 |
| 부활 | 게임오버 후 1회 이어하기 |

MVP에서는 파워업을 제외한다.  
1차 확장에서는 `보호막` 1종부터 구현한다.

## 12. MVP 구현 범위

1차 구현 목표는 “플레이 가능한 핵심 재미”를 만드는 것이다.

### 12.1 포함 기능

- 단일 탭 입력
- 병아리 점프
- 발판 착지 판정
- 발판 자동 생성
- 카메라 수직 추적
- 점수 증가
- 게임오버
- 결과 화면
- 최고 점수 저장
- 씨앗 재화 획득
- 기본 장애물 1종

## 15. 수익화 방향

MVP에서는 수익화를 구현하지 않는다.  
추후 버전에서 다음 기능을 검토한다.

- 광고 보고 보상 2배
- 광고 보고 부활
- 광고 제거 상품
- 프리미엄 병아리 스킨
- 한정 꾸미기 패키지

수익화는 플레이 흐름을 과도하게 끊지 않는 방향으로 설계한다.

## 18. 기획상 남은 결정 사항

- 병아리 점프가 자동 방향인지, 다음 발판을 향한 고정 점프인지 결정
- 발판이 좌우로 움직이는지, 병아리가 좌우로 이동하는지 결정
- 충돌 판정을 물리 기반으로 할지, 영역 판정 기반으로 할지 결정
- 병아리 스킨에 능력치를 줄지 결정
- 둥지 꾸미기를 언제 구현할지 결정
- 광고와 IAP를 어느 시점에 붙일지 결정

## 19. 결론

`JumJump`의 1차 목표는 레퍼런스의 핵심 재미인 “탭 타이밍 기반 수직 상승”을 병아리 콘셉트로 재구성하는 것이다.  
초기 개발에서는 수집, 광고, 꾸미기보다 코어 조작감과 반복 도전의 재미를 우선 검증한다. 이후 스킨, 재화, 둥지 꾸미기, 광고 보상 구조를 단계적으로 추가한다.
